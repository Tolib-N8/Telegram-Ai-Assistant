# 🤖 Telegram AI Assistant

Интеллектуальный Telegram-ассистент для **личного аккаунта**, который автоматически
отвечает незнакомым пользователям, фильтрует входящие сообщения и уведомляет владельца
только о действительно важных обращениях.

Ассистент использует **Google Gemini AI** и работает через **Telethon**.

---

## 🚀 Возможности

- ✅ Автоответчик для **незнакомых контактов**
- 🧠 Генерация умных ответов через **Gemini AI**
- 🎤 Поддержка **голосовых сообщений**
- 🔔 Уведомления владельца в «Избранное»
- 💾 Сохранение состояний диалогов
- 🔒 Безопасная работа через `.env`
- 🧍 Работает от имени **Telegram-аккаунта**, а не бота

---

## 🧩 Логика работы

1. Если пишет **контакт из адресной книги** — ассистент не вмешивается  
2. Если пишет **незнакомец**:
   - ассистент вежливо уточняет цель обращения
3. После ответа пользователя:
   - сообщение пересылается владельцу
   - диалог корректно завершается
